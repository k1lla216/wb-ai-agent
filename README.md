# 🤖 WB AI Automation Agent

Комплекс прикладных AI-агентов для автоматизации операционных, складских и финансовых процессов селлера Wildberries.

Проект построен на принципах **Deterministic Verification** (разделение NLU-логики нейросети и строгих детерминированных вычислений) и **Safety-First Routing** (блокировка автоответов при репутационных и юридических рисках).

---

## 🛠 Стек технологий
* **Язык:** Python 3.11+
* **Фреймворк бота:** `aiogram 3` (асинхронный Telegram Bot API)
* **LLM Engine:** `Google Gemini API` (`gemini-3.5-flash-lite`)
* **Валидация данных:** `Pydantic`, `JSON Schema` / Structured Outputs
* **Окружение:** `python-dotenv`, `asyncio`

---

## 🚀 Реализованные бизнес-сценарии

1. Агент клиентского сервиса и модерации отзывов
* **Позитивные сценарии (4–5 звёзд):** генерация персонализированного ответа с подтягиванием технического контекста модели из базы знаний (`products.json`) и инлайн-кнопками публикации на маркетплейс.
* **Негатив с нарушением регламента (1–3 звезды):** автоматическая сверка жалобы со `strict_rules`. Вежливое разъяснение причин неисправности (например, залив аромамасла в бак увлажнителя) и передача контактов гарантийной поддержки.
* **Safety-Critical эскалация:** обнаружение признаков ЧП (короткое замыкание, пожар, искры) и юридических угроз (суд, Роспотребнадзор). Автоматическая блокировка автоответа и отправка тревожного алерта руководству.

2. Складской агент контроля остатков (FBO)
* Обработка запросов на естественном языке («Что у нас по остаткам чайников?»).
* Детерминированный расчёт оборачиваемости: `Остаток / Скорость продаж в день`.
* Пороговый триггер автозаказа: при запасе $\le 7$ дней формируется проект заявки на поставку партией пополнения с подтверждением в один клик.

3. Финансовый аудитор Unit-экономики и фактчекинг
* Принцип нулевого доверия к текстовым отчётам менеджеров.
* NLU-извлечение ключевых метрик из свободных сообщений с последующей верификацией по первичным данным (`finance.json`):
  $$\text{Чистая прибыль} = \text{Выручка} - \text{Себестоимость} - \text{Комиссия WB} - \text{Логистика} - \text{Реклама}$$
* Подсветка расхождений от 100 ₽ с точным указанием суммы отклонения и детализацией статей расходов.
