# Telegram-бот для автоматизации рутины селлера Wildberries

Проект автоматизирует три частые задачи в работе с маркетплейсом: обработку отзывов, контроль товарных остатков на FBO и экспресс-аудит отчётов по Unit-экономике.

Главный упор сделан на надёжность: LLM используется только там, где нужен разбор текста на человеческом языке. Все расчёты, бизнес-правила и финансовые формулы выполняются строго кодом на Python, чтобы исключить галлюцинации нейросети.

---

## Стек
* Python 3.11+
* aiogram 3 (асинхронный бот)
* Google Gemini API (`gemini-3.5-flash-lite`)
* Pydantic / Structured JSON
* python-dotenv

---

## Как это работает

### 1. Модерация отзывов и клиентская поддержка
* **Позитивные отзывы (4–5 звёзд):** бот берёт данные о товаре из `products.json` и собирает персональный ответ с упором на ключевые преимущества модели. Ответ не уходит на маркетплейс сам — менеджер видит кнопки «Одобрить» и «Изменить».
* **Жалобы и негатив (1–3 звезды):** сверяет текст отзыва с правилами эксплуатации (`strict_rules`). Если покупатель нарушил инструкцию (например, залил эфирное масло прямо в бак увлажнителя), бот корректно объясняет причину поломки и даёт контакты сервисного центра.
* **ЧП и юридические риски (Safety Check):** при упоминании пожара, короткого замыкания, суда или Роспотребнадзора автогенерация ответа блокируется. Бот отправляет тревожный алерт менеджеру с кратким содержанием проблемы.

### 2. Контроль остатков на складе и проект поставки
* Понимает запросы в свободной форме («Сколько осталось чайников?», «Что на исходе?»).
* Считает оборачиваемость по формуле: `Остаток / Скорость продаж в день`.
* Если запаса остаётся меньше чем на 7 дней, бот предупреждает об out-of-stock и сразу предлагает сформировать поставку на нужный объём. Менеджер может подтвердить заказ инлайн-кнопкой в чате.

### 3. Сверка финансовых отчётов (Unit-экономика)
* Позволяет быстро проверить текстовый отчёт менеджера по реальным данным маркетплейса (`finance.json`).
* Модель парсит из текста артикул и заявленную прибыль, а Python пересчитывает фактическую маржу:  
  `Выручка − Себестоимость − Комиссия WB − Логистика − Реклама`
* Если заявленная цифра расходится с первичкой больше чем на 100 рублей, бот подсвечивает ошибку, указывает точную разницу и расписывает все статьи расходов.

---

## Структура файлов
* `main.py` — хэндлеры бота, логика маршрутизации и валидации.
* `products.json` — база характеристик и гарантийных правил по товарам.
* `inventory.json` — симуляция таблицы остатков и продаж на FBO.
* `finance.json` — первичные финансовые выгрузки по артикулам.

## Установка и запуск

1. Клонировать репозиторий:
git clone [https://github.com/k1lla216/wb-ai-agent.git](https://github.com/k1lla216/wb-ai-agent.git)
cd wb-ai-agent

2. Установить зависимости:
pip install -r requirements.txt

3. Создать файл .env в корне проекта и указать ключи:
TELEGRAM_BOT_TOKEN="токен_бота_от_BotFather"
GEMINI_API_KEY="api_ключ_google_gemini"

4. Запустить:
python main.py
